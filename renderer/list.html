언제든 꺼내 쓰는 나만의 메모장

안녕하세요! nagi memo에 오신 것을 환영합니다.

Windows 기본 메모 앱에서 영감을 받아,
더 자유롭고 풍부한 메모 경험을 담았습니다.
포스트잇처럼 바탕화면에 메모를 붙여두고,
언제든 꺼내 아이디어를 기록하세요.

아래 › 버튼으로 주요 기능을 살펴보세요

메모 창 — 기본 조작
상단 제목 표시줄을 드래그해 창을 이동하세요. 창 하단·모서리를 드래그하면 크기를 조절할 수 있으며, 위치와 크기는 자동 저장됩니다.
핀 버튼을 누르면 메모가 다른 창 위에 항상 떠 있습니다. 핀 된 메모는 작업 중에도 항상 보입니다.
투명도 버튼을 클릭하면 슬라이더가 나타납니다. 20~100% 사이로 조절해 바탕화면이 비쳐 보이도록 할 수 있습니다.
숨기기(─) 버튼을 누르면 메모가 작은 버블로 최소화됩니다. 버블을 클릭하면 다시 펼쳐집니다.
Ctrl+L로 편집 잠금을 켜고 끕니다. 잠금 상태에서는 내용이 보호되며, Sticky Notes 모드에서는 마우스 클릭스루도 활성화됩니다.
+(새 메모) 버튼 또는 Ctrl+N으로 새 메모를 만드세요. 메모 우상단 ⋯ 메뉴나 우클릭으로 답글(스레드)을 달 수도 있습니다.
텍스트 서식 & 단축키
Ctrl+N새 메모 만들기 Ctrl+B굵게 Ctrl+I기울임꼴 Ctrl+U밑줄 Ctrl+⇧+X취소선 Ctrl+⇧+H형광 하이라이트 Ctrl+K링크 삽입 Ctrl+F메모 내 텍스트 검색 Ctrl+Z / Y실행취소 / 다시실행 Ctrl+L편집 잠금 켜기/끄기
링크를 더블클릭하면 URL을 직접 수정할 수 있습니다. 우클릭 컨텍스트 메뉴에서 글자 색상 변경, 주석(코멘트) 추가도 가능합니다.
자동변환 — 블록 요소

편집 중 아래 문자를 입력하고 Space를 누르면 자동으로 블록이 삽입됩니다.

- 또는 *글머리 목록 (Bullet List) 1.번호 목록 (Ordered List) [ ]체크박스 (Checkbox) ---수평 구분선 (Divider) ```코드 블록 (Code Block) >>토글 접기 블록 (Toggle)
리스트 항목 안에서 Tab으로 들여쓰기, Shift+Tab으로 내어쓰기를 할 수 있습니다. 빈 항목에서 Backspace를 누르면 서식이 해제됩니다.
토글 블록(>>)은 클릭으로 내용을 접고 펼칩니다. Enter 키로 내부 편집 영역으로 진입하며, 내부에서 모든 서식과 중첩 토글을 사용할 수 있습니다.
이미지 & 프로필
클립보드 이미지를 Ctrl+V로 붙여넣거나, 이미지 파일을 메모 본문에 드래그 앤 드롭하면 자동 추가됩니다. 최대 1920px로 자동 압축 저장됩니다.
삽입된 이미지를 클릭하면 이미지 에디터가 열립니다. 회전·좌우·상하 반전·확대/축소·드래그 이동으로 구도를 잡고 적용할 수 있습니다.
좌상단 아바타 이미지를 클릭하면 프로필 사진을 변경합니다. 선택 즉시 이미지 에디터가 열립니다. 아바타 옆 이름·핸들 영역을 클릭해 수정하세요.
아바타를 우클릭하면 현재 프로필(이름·사진·뱃지)을 저장하거나 불러올 수 있습니다. 여러 캐릭터를 미리 만들어 빠르게 전환해보세요.
하단 컬러 도트를 클릭하면 메모 테마 색상을 변경합니다. 우상단 달·해 버튼으로 다크/라이트 모드를, 폰트 버튼(Aa)으로 글꼴·크기를 조절하세요.
목록 뷰 & 검색
메모 창의 목록 버튼을 클릭하거나 트레이 아이콘 우클릭 → 목록 열기로 목록 뷰를 띄웁니다. 모든 메모를 한 화면에서 확인하고 관리합니다.
상단 검색창에 입력하면 메모 내용·이름·태그를 실시간으로 검색합니다. 결과 목록에서 ↑↓ 방향키로 이동할 수 있습니다.
필터 바 우측 정렬 선택기로 수정일순 / 생성일순 / 이름순을 선택합니다. 전체·좋아요·휴지통·태그 필터 칩으로 원하는 메모만 표시하세요.
미리보기 패널 하단 태그 입력창에 이름을 쓰고 Enter를 누르면 태그가 추가됩니다. 한글·영문·숫자·_ 사용 가능, 최대 20자입니다.
목록 항목 우클릭 → 다중 선택으로 여러 메모를 한번에 삭제하거나 JSON으로 내보낼 수 있습니다. 검색·필터 중 내보내기 버튼은 현재 보이는 메모만 저장합니다.
데이터 관리
목록 창 상단 백업(↓) 버튼으로 모든 메모를 JSON 파일로 내보냅니다. 검색·필터가 활성화 중이면 현재 보이는 메모만 저장합니다.
불러오기(↑) 버튼으로 JSON 백업을 복원합니다. 이미 존재하는 메모는 건너뛰고 새 메모만 추가되므로 중복 걱정 없이 사용할 수 있습니다.
자동 백업: 앱 실행 중 7일마다 자동으로 백업 파일을 생성합니다. 최근 5개까지 보관하며, 저장 위치는 설정 → 데이터 경로에서 확인할 수 있습니다.
삭제한 메모는 즉시 사라지지 않고 휴지통으로 이동합니다. 목록 → 휴지통 필터에서 복구하거나 영구 삭제할 수 있으며, 30일 후 자동 완전 삭제됩니다.
목록 창 설정(⚙) → 데이터 경로 열기를 누르면 메모 데이터가 저장된 폴더를 바로 열 수 있습니다. 수동 백업이나 이전 시 유용합니다.
